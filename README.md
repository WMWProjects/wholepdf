# WholePDF

Merge any number of files into one PDF, privately, on your own computer. By Wholeminds Wellness.

**Open:** https://wmwprojects.github.io/wholepdf/ in Google Chrome, then click **Install App** (top right) to add WholePDF to your Dock.

## Privacy

- Everything runs inside your browser. Files are never uploaded; the page is locked with a Content Security Policy that blocks all network connections from the app.
- This repository contains only the app's code. It never contains documents or client information.

## What It Merges

PDFs, images, fax TIFFs, zip files, text, emails (.eml), and Word / Excel / PowerPoint (as text). Extras: bookmarks, page numbers, separator pages, AES-256 password protection, form flattening.

Built on pdf-lib (MIT) and JSZip (MIT).
